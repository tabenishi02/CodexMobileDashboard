# 表示用JSONサンプル

このディレクトリのデータはすべて架空であり、実際のCodexセッション、ユーザー名、パス、秘密情報を含まない。

## ディレクトリ

- `normal/`：スキーマ`1.0`の正常な1スナップショット。
- `invalid/`：異常処理を確認するための意図的な不正データ。
- `large/`：長文の分割・復元を試す生成スクリプト。

正常サンプルの共通値は次のとおり。

- `snapshot_id`: `sample-20260804T153000-000001`
- `workspace_id`: `sample-project`
- `session_id`: `00000000-0000-7000-8000-000000000001`

`invalid/invalid-json.json`だけは意図的にJSON構文を壊している。テストコードがこのファイルを読み込めないことが正常な結果となる。
