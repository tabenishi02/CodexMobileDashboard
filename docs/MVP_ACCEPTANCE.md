# MVP完了条件

v0.1.0の最終判定結果は[`MVP_ACCEPTANCE_RESULT_V0.1.0.md`](MVP_ACCEPTANCE_RESULT_V0.1.0.md)を参照する。

## 判定方法

MVPは、実装タスクの消化数ではなく、作業用PC、Androidサーバー端末、閲覧スマートフォンを接続した受入確認の結果で判定する。MVPの実機受入確認には、動作確認済みの基準端末である検証用Android端末をAndroidサーバー端末として使用する。本書の必須条件をすべて満たし、未解決の`critical`または`error`相当の不具合が残っていない時点をMVP完成とする。

各確認では、前提条件、操作、期待結果、実際の結果、確認日時、確認環境、証拠となるログ・JSON・画面を記録する。

## 必須条件

### MVP-01 一連動作

作業用PCでCodex JSONLを収集・整形し、認証付きHTTPS POSTでAndroidサーバー端末へ送信し、端末がHTTPSで保存・配信したJSONを閲覧スマートフォンのブラウザで表示できる。

### MVP-02 セッションデータの完全性

採用済みの実データを含むCodex JSONLを、対象テキストの欠落、順序の入れ替わり、文字化け、重複なく処理できる。収集ツールを再起動しても保存済み位置から処理を再開し、処理済みメッセージを重複登録しない。

### MVP-03 Git変更メタデータ

追加、修正、削除、名前変更、コピー、種類変更、競合、未追跡、ステージ状態、追加・削除行数、バイナリ判定を正しく取得し、スマートフォンに表示できる。セッション中にコミットされた変更も追跡できる。

### MVP-04 送信対象の制限

プロジェクトのファイル本体、ソースコード本文、Git差分本文、画像などのファイル本体をGit収集データとしてAndroidサーバー端末へ送信しない。Codex JSONL内にテキストとして記録されたコードはセッション履歴として扱う。

### MVP-05 大容量テキスト

長文を削除・省略せず、定めたサイズで分割、送信、保存、復元できる。256KiBを超える単一メッセージを複数断片に分け、各HTTPリクエストを1MiB以下に保ち、先頭から末尾まで欠落なく復元できる。

### MVP-06 スマートフォンでの確認

スマートフォンから、現在の作業状況、チャット、エラー、決定事項、変更ファイル、次の作業、システム状態を確認できる。通信中、データなし、通信失敗、古いデータを区別でき、手動更新と表示中の自動更新が動作する。

### MVP-07 障害と再起動からの復旧

作業用PC、収集ツール、Androidサーバーの再起動後に、保存済みデータと処理位置を失わず再開できる。通信障害時は未送信データを保持し、Androidサーバー端末の復旧後に再送し、重複保存しない。不正データや途中の書き込み失敗で既存の正常な保存データを壊さない。

### MVP-08 秘密情報の保護

認証なしまたは誤ったトークンの送信を拒否する。通常運用ではHTTPSを必須とし、正しいプライベートCAでサーバー証明書と接続先を検証する。証明書エラー、平文HTTP、誤ったCAでの実データ送受信を拒否する。トークン、APIキー、パスワード、CA秘密鍵、サーバー秘密鍵を送信データ、表示、運用ログ、Git管理対象へ含めない。パストラバーサルと許可されていない保存先への書き込みを拒否する。

### MVP-09 運用手順

PCとAndroidサーバー端末の初期設定、秘密情報の配置、起動・停止、スマートフォンからの接続、ログ確認、通信障害時の確認、バックアップ、再起動後の復旧手順が文書化され、その手順だけで環境を復旧できる。

### MVP-10 未解決不具合

未解決の`critical`または`error`相当の不具合が残っていない。軽微な表示上の問題は、影響、回避方法、対応予定を既知の問題として記録した場合に限りMVP完成を妨げない。

## 主な受入確認例

- Codexのターン完了後、Androidサーバー端末への送信を即時開始し、スマートフォン表示中なら端末受信後15秒以内に反映する。
- 収集ツールを再起動しても同じメッセージを重複登録しない。
- 修正、新規追加、削除、名前変更、未追跡、画像変更を含むテスト用Git状態を正しく表示する。
- Androidサーバー端末に保存されたJSONにプロジェクトファイルやGit差分本文が含まれないことを確認する。
- 600KiBのテストメッセージを分割して送信し、全文を復元する。
- Androidサーバー端末の停止中に生成したデータをPCが保持し、復旧後に重複なく再送する。
- 不正JSON、サイズ超過、認証失敗、パストラバーサルを拒否し、既存データを維持する。
- 基準端末の検証用Android端末と作業用PCを再起動し、文書化した手順だけで閲覧を復旧する。

## MVP対象外

次の機能は、なくてもMVP完成と判定する。

- スマートフォンからのファイル編集またはCodex操作
- プロジェクトファイル本体とGit差分本文の閲覧
- 複数ワークスペースを同時比較する画面や高度な切替UI
- インターネット経由の接続とTailscale
- PWA、WebSocket、SQLite
- 全文検索、Wiki自動生成、音声要約
- 高度なコードビュー、グラフ、利用統計
